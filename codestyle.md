# Frontend Code Style

Source: Google JavaScript Style Guide — https://google.github.io/styleguide/jsguide.html

- Two-space indentation, semicolons, single-quoted JavaScript strings.
- Semantic HTML, explicit accessible names and visible keyboard focus.
- Use textContent for values from requests and users.
- Keep calculation in the backend; only expression editing and rendering belong here.
- Catch network errors and show actionable messages; never silently substitute local calculation.
